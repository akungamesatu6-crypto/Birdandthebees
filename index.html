    よくある質問FAQ

    ミントの仕組み、BNTBボーナス、マーケットプレイスについて、よく寄せられる質問をまとめました。

    ♥無料ミントの条件を教えてください▾
    Agent ID 保有者限定で、1ウォレットにつき1回までです。無料ミントは必ずBluebird（コモン）になり、無料プールは全4,444点のうち3,000点までです。
    ♥有料ミントでBluebird（コモン）が出ることはありますか？▾
    ありません。有料ミントの抽選対象は Honeybee から True Love までです。Bluebirdは無料ミントだけのものです。
    ♥Royal DuoとTrue Loveはどうすれば当たりますか？▾
    単品ミント（0.0005 BNB）でも当たります — 確率はとても小さいですが、チャンスはあります。5個パック（0.0024 BNB）なら5回抽選でき、トッププールへの振り替えチャンスもあるので、少しだけ当たりやすくなります。当選は保証されません — あくまでチャンスです。
    ♥BNTBボーナスはどうやって受け取れますか？▾
    有料ミント1回ごとに、引いたレアリティに応じたボーナスが付与されます：コモン 1,000、アンコモン 2,000、レア 4,000、エピック 8,000、レジェンダリー 16,000、リミテッド 32,000 BNTB。1ウォレット最大 160,000 BNTB までです。無料ミントにボーナスはありません。
    ♥1つのウォレットで何個までミントできますか？▾
    最大6個まで — 無料ミント1回 + 有料ミント5回です。
    ♥マーケットプレイスはいつ開きますか？▾
    ミント開始と同時にオープンします。保有者は6つのティアすべてを出品・取引できます。
